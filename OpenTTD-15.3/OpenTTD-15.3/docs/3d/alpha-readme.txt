OpenTTD 3D - Alpha preview for Windows x64

Unzip the entire game folder into a writable location, then double-click
"Play OpenTTD 3D.cmd". Start a new temperate game or load a compatible save.
The launcher enables 3D and contact shadows. Settings and saves use the
package's own profile. Microsoft runtime DLLs and OpenGFX are included.
Sound and music are disabled; sound/music packs are not bundled.

Scope: Windows OpenGL, temperate base-game content. Other climates have
unfinished art. Gameplay NewGRFs are disabled by the launcher. Full detail
is the default. This is an unofficial experimental fork of OpenTTD 15.3.
Multiplayer compatibility with official OpenTTD or other builds is unverified.

Use the 3D toolbar button for settings and camera help. If there is a graphics
problem, the console command "renderer_3d off" restores classic rendering.
Keep existing saves backed up when testing. Load games from their existing
location and save test copies into this package's profile.

For a bug report, include build-info.json, GPU and driver, Windows/display
scaling, map size, camera mode, steps to reproduce, a screenshot and a save
if relevant. Say whether the problem also occurs in classic rendering.
Check screenshots and saves for information you do not want to share.

The matching source ZIP is named in build-info.json. It contains game source,
editable model assets, generated headers and build/package instructions.
Publish it alongside the game download. The source ZIP also contains the
matching OpenGFX 7.1 source under thirdparty-sources/.
License notices are in COPYING.md, README.md, licenses/ and the OpenGFX tar.

This preview has not completed clean-machine, weaker-GPU or all native
interaction checks. See docs/alpha-release.md for the remaining checklist.
